# ABC Areal (Dinamo Typefaces)

Commercial font, supplied by the owner on 13 October 2026. Files are the
original WOFF2s, unmodified. Dinamo's terms forbid converting formats or
modifying the fonts. The terms are in `Dinamo Licensing Terms.pdf` and must
travel with the fonts.

**Before using these anywhere, the license on the Tropical Futures invoice
must cover it:**

- Hosted dashboard (e.g. Railway): needs a **web license** for that one
  domain (subdomains included), or an app license if Dinamo classes this as
  a web app. Not verified as of 13 Oct 2026.
- Keep this repository **private**. The terms forbid putting the fonts in
  public repositories or on public servers, and sharing them with third
  parties.
- Don't embed them in pages hosted on other domains (e.g. claude.ai
  previews), and don't base64-convert them.

If the repository ever becomes public, remove this folder and its history
first. Without the files, the app falls back to Arial/Helvetica.
